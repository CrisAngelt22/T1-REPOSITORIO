T1 – Caso 1: Billetera Digital

Descripción
Aplicación web desarrollada con Java Servlet y JSP que permite realizar recargas, registrar gastos y consultar el historial de movimientos.

Versiones utilizadas
- Java JDK 21.0.6
- Apache Maven 3.9.16
- Apache Tomcat 10.1
- Java Servlet y JSP
- JSTL
- Bootstrap

Funcionalidades
- Saldo inicial de S/ 250.00.
- Registro de recargas.
- Registro de gastos.
- Validación de montos.
- Verificación de saldo disponible.
- Historial de movimientos.
- Almacenamiento mediante HttpSession.

Pasos de ejecución

1. Instalar Java JDK 17 o superior, Maven y Tomcat 10.1.
2. Abrir la carpeta del proyecto.
3. Ejecutar `mvn clean package`.
4. Buscar el archivo `target/billetera-servlet.war`.
5. Copiar el archivo WAR a `C:\Tomcat10\webapps`.
6. Iniciar Tomcat ejecutando `C:\Tomcat10\bin\startup.bat`.
7. Abrir en el navegador:

   http://localhost:8080/billetera-servlet/

Pruebas funcionales

- Recarga de S/ 100.00: saldo S/ 350.00.
- Gasto de S/ 50.00: saldo S/ 300.00.
- Gasto de S/ 400.00: operación rechazada por saldo insuficiente.
- Montos negativos, cero o vacíos: operaciones rechazadas.

Almacenamiento
Los datos se mantienen temporalmente en la sesión HTTP. No se utiliza base de datos.
